# Chase Barlow portfolio — GitHub Pages files

These files are ready to publish from the root of the `chasebarlow.github.io` repository.

## Publish

1. Download and unzip `Chase-Barlow-GitHub-Pages.zip` on your computer.
2. Open https://github.com/chasebarlow/chasebarlow.github.io and sign in.
3. Choose **Add file → Upload files**.
4. Drag the *contents* of the unzipped folder into the upload area. Upload `index.html`, `.nojekyll`, and the `engine`, `marks`, and `media` folders, plus `resume.pdf` and this README. Do not upload the outer folder as one nested folder.
5. Select **Commit changes** and commit to the `main` branch.
6. If GitHub Pages is not already enabled, open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
7. Wait a minute or two, then visit https://chasebarlow.github.io.

The portfolio is a static site. Its page, PDF, video, and supporting assets are included here. Uploading the files replaces matching files in the repository, so keep any unrelated files already in the repo.
