# Chase Barlow Portfolio

Static portfolio for https://chasebarlow.github.io/.

## First publication
1. Create a public repository named chasebarlow.github.io in the chasebarlow account. Initialize it with a README.
2. Unzip Chase-Barlow-GitHub-Portfolio.zip on your computer.
3. In the repository, choose Add file > Upload files. Upload the CONTENTS of the extracted folder, including index.html and the engine, media, and marks folders. Do not upload the ZIP or put everything inside an extra folder.
4. Commit the upload to main.
5. Open Settings > Pages. Set Source to Deploy from a branch, branch main, folder /(root), and Save.
6. Wait for the Pages deployment to finish, then open https://chasebarlow.github.io/.

## Updating
Edit index.html for text, experience, education, skills, and project ordering. Upload changed files into their original locations and commit. GitHub Pages publishes updates automatically.
The reactor lives in engine/reactor.js. Keep the engine folder intact.
The at-sea video lives in media/at-sea.mp4. School marks live in marks/.
Photos and resume/project PDFs are embedded in index.html; ask ChatGPT to replace them when needed.
No build command or additional dependencies are required.
